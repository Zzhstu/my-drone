# 半仓库 G1 / MID360 仿真配置

来源是复制的 `src(1)/src/p450_experiment`，不是本次实机标定。`config/spirecv_config/calib_g1_720.yaml` 记录 1280×720、fx=573.8293227、fy=574.8509551、cx=627.8484632、cy=344.5207170，畸变 [0.0087554, -0.0265125, -0.00821276, -0.00680909, 0.01214029]，平均重投影误差 0.389 px。`launch_spirecv/gimbal_server.launch` 设置 G1、1280×720、30 FPS；标定文件与该具体硬件、变焦状态是否一致仍需实机核实。

半仓库新采集的相机使用 1280×720、3 Hz，保留实时负载控制；以 fx 建立水平视场约 96.2407° 的理想针孔，仿真 K 为 fx=fy=573.8293227、cx=640、cy=360，D=0。它只是中心主点、方形像素近似，未模拟实测 D、fy 差异或主点偏移，不能称为真实相机原始图像，也不是依据实测 D 去畸变得到的图像。G1 本身可控制云台，仿真仍为原固定 D435i 占位外壳和安装位置，无 G1 云台转动及实测 G1—LiDAR 外参。相机 profile 记录了来源参数和差异。

`launch_mid360/msg_MID360.launch` 配置 10 Hz；`config/mid360_config/mid360.yaml` 设置 blind=0.5 m、scan_line=4、360°、算法 det_range=100 m、外参平移 [-0.011,-0.02329,0.04412]，该配置订阅飞控 IMU，不能直接当作 MID360 内置 IMU 标定。本仿真仍使用 MID360 内置仿真 IMU，由 SDF 几何计算外参，点云转为仿真 PointCloud2；仿真算法实际 det_range=25 m，雷达模拟射程上限 40 m，并非真实最大射程。原有非重复扫描 CSV 保留；仅半仓库每次运行私有副本把额外竖直扫描偏移由 15° 改为 0°。配置中的探测距离和 FAST-LIO 参数不等同雷达物理视场。原有资产、旧采集和模型不变。

新规划按新投影计算；旧路线在运行时标记需重新检查可见性。旧覆盖结果、旧训练模型和新视场不能混同；变更扫描角后需重新验证起飞、定位、覆盖与重建，静止预检不代表完成飞行。
