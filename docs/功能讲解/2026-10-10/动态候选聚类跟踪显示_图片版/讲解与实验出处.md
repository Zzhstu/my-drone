# 动态候选、聚类、跟踪与显示：图文讲解

本目录只交付图片，不生成PPT，也不改变demo。七张PNG均为3840×2160、16:9；SVG中的中文、框线、人物点云、货架、箭头和统计图均可编辑。01—05是根据当前源码绘制的机制示意，06嵌入完整历史截图，07依据原始测试JSON重绘。示意中的人物、货架和路径不按真实比例，不作为实验结果。

## 1. 模块要解决什么问题

雷达每次看见的点不完全相同。无人机移动、遮挡变化、雷达采样变化、新区域出现、位姿估计误差，都可能让静态物体的局部点发生变化。直接把“本帧和背景不同”视为运动，会把货架边缘、树叶等误判；反过来，长时间把前景永久吸收入背景，又可能让暂停后继续走动的行人不再进入检测。

本模块分四层处理：先找差异候选，再把邻近点组织为簇；利用过去一小段时间的中心位置判断持续运动；最后输出运动对象、确认簇点和显示标记。**候选、确认运动、显示球、碰撞风险不是同一件事。** 一个目标被确认移动，不代表它会与无人机相撞；风险在下游单独计算。显示球只是方便观察，不是人体轮廓、真实尺寸或安全半径。

实际数据流：

```text
当前地图坐标扫描 + 无人机位姿
    ↓
候选提取：/uav1/foreground_points
    ↓                         稳定静态地图提供背景支持
聚类节点：点簇 → 中心关联 → 运动历史 → 确认/预测/丢失
    ├─ /uav1/dynamic_points      本帧已确认簇的候选点
    └─ /uav1/dynamic_objects     编号、中心、速度、预测标志
         ├─ 显示节点 → /uav1/dynamic_markers
         ├─ 地图维护节点
         └─ 类别接口（默认透传）→ 动态风险节点
```

这里没有将独立预测节点或遗留跟踪器强行串到主链。FAST-LIO内置dynamic_filter是另一条可选算法，本demo运行器关闭该开关，不能把其规则混为这里的候选检测。

## 3. 第01页：模块架构

输入是已经统一到map坐标的**当前帧**，不是带历史点的累计地图。如果用累计地图做候选，旧物体会被反复处理，失去“这一帧实际看到了什么”的时间含义。桥接负责坐标变换；检测器检查frame_id是否匹配，不会只修改标签来实现变换。无人机位姿用于检测范围和近场判断，不是再次对当前扫描进行完整运动补偿。

位姿估计与坐标对齐可以减轻自身运动造成的变化，但不能保证完全消除误检。当前仿真MARSIM路径不等于真实MID360逐点补偿已经验证；本图只写统一坐标，不宣称验证过真实传感器的逐点去畸变效果。

## 4. 第02—03页：候选和聚类的规则

1. 剔除无效点，用0.25米体素降低密度；比较和输出以体素为单位，候选输出为格子中心。
2. 只保留相对无人机高度−0.60～+1.20米、三维距离不超过6米的点。没有收到里程计时范围筛选暂时失效，当前没有保证里程计新鲜度；不是严格同步的安全输入门控。
3. 将初始40次有效非空云回调的格子取并集形成背景。**这是出现过即可加入，不是40次多数投票，也不是40秒。** 初始化阶段发布空候选。初始化云经过上述窗口筛选；飞行过程中高度变化会改变可用点。
4. 按背景体素的邻近格子抑制差异。当前配置一般与近场均为邻域1，即含自身的3×3×3格；构造函数里的近场0不是目前yaml的实际值。靠近背景的动态回波也可能被抑制。
5. 默认关闭永久在线背景学习。它避免把暂停或反复走同一路径的前景永久吸收，但会让新看到的静态结构继续成为候选，由后级进一步筛选；不是无代价的“彻底解决”。
6. 用0.55米邻近连接建立点簇，每簇4～1000个候选点。连接是逐点串联，**0.55米不限制整个簇的总直径**；相邻目标可能合并，一个目标也可能裂为多个簇。
7. 中心是候选格子中心的平均位置，不是人体几何中心或三维框检测结果。当前没有“必须像人”的高度、宽度、类别或外形筛选。

静止人体仍是真实障碍，应保留即时碰撞占用。初始化时人已站在原地，可能进入背景；人体启动、离开背景重合区域后才可能形成足够候选。当前方案不是对静止人进行语义去除，也不保证这种起步过程都能及时检出。

## 5. 第04页：静态支持与多条件运动确认

静态支持检查见[hasStableStaticSupport](/home/a/AstraDroneOpen/AstraDrone_ros1_ws/src/SLAM/fastlio_bridge/src/dynamic_cluster.cpp:281)。稳定地图至少30点时，对簇内每个候选点搜索0.35米范围；至少60%的点能找到背景支持，本次moving判断为不通过。这是背景一致性约束，不是人体分类。稳定地图不够时否决不生效；站立人体已经进入稳定地图或与货架混在一起时，也可能否决真实运动候选。收到地图时会重新转换整张点云并建立空间索引，存在算力开销，未在本轮测量。

匹配后最多保留12个平滑历史中心，用最小二乘拟合三维速度。运动确认默认看水平位移和速度；上下抖动不直接触发，但三维位置仍参与聚类、关联和速度有效性检查。不是惯性积分获得目标速度，也不是卡尔曼状态估计。

| 条件 | 一般区域 | 水平距离小于3米 |
| --- | --- | --- |
| 轨迹历史跨度 | 至少0.50秒 | 至少0.45秒 |
| 水平净位移 | 大于0.20米 | 大于0.18米 |
| 水平拟合速度 | 大于0.30米/秒 | 大于0.32米/秒 |
| 方向一致性 | 至少0.82 | 至少0.80 |
| 匀速拟合误差 | 不超过0.10米 | 不超过0.10米 |
| 有效三维拟合速度 | 有限且小于3米/秒 | 同左 |
| 连续合格次数 | 4次 | 4次 |

方向一致性是净位移占走过路径长度的比例，来回抖动小、持续同向大；不是已校准的动态概率。拟合误差反映历史中心偏离短时匀速轨迹的程度。各条件同时满足才累计motion_count；不满足就清零。**4次是在历史跨度等门限达到之后继续连续合格，不是“4帧后必定检出”。** 12个历史样本与频率共同决定能否满足0.45/0.50秒，改采样频率需联动验证。

已确认动态目标若连续3次运动判定不合格，会取消动态状态；这并不代表目标真的静止，更不代表空间空了。急转弯、低速、遮挡、中心偏移等也会导致不合格。站立实体仍需下游当前点云与静态风险保护。

## 6. 第05页：关联、短时预测和显示更新

关联见[association_gate](/home/a/AstraDroneOpen/AstraDrone_ros1_ws/src/SLAM/fastlio_bridge/src/dynamic_cluster.cpp:913)。当前簇中心在历史目标的匀速预测中心附近寻找最近匹配；门限随距离上限、位置容差和采样时间差调整，一般上限0.80米/容差0.20米，近场上限1.00米/容差0.30米，假定关联最大速度3米/秒。一个历史轨迹本帧最多被一个簇使用。这里是顺序贪心关联，不是全局最优多目标分配；交叉、合并、裂分可能换编号。

中心输出对新测量使用0.65权重，使显示跟得较快；运动历史独立以0.20权重平滑，速度输出也用0.20。这解决的是两类输出的权衡，不意味着没有跟随迟滞，更不改变运动门限。

未匹配到已确认动态目标时，从最后真实中心和速度短时外推。最多允许4次候选回调丢失，第5次删除轨迹。预测副本不覆盖最后观测中心/时间戳，避免重复累加时间差。仅预测输出不会生成新的动态点云。**次数不是固定秒数；上游完全停止回调时，轨迹删除不会自己计时触发。** 取消确认的轨迹可暂留内部，直到连续丢失超过4次删除，但不会作为动态目标继续输出。

显示节点按轨迹编号生成直径0.3米的球：本帧实际观测到的确认目标为红色，预测目标为红橙色（RGB=1,0.6,0），位置来自对象消息。每次消息中不存在的旧编号发送删除动作；标记有效期0.5秒。该有效期使用ROS时间，仿真暂停时不能当墙钟0.5秒倒计时。聚类和显示输入队列都是1，减少旧数据积压，但不代表完整端到端链路只有1条或已经证明无延迟。

对象的0.60×0.60×1.20米尺寸是默认值，不是拟合出的人体框。confidence字段取轨迹方向一致性；semantic_class为0表示未分类，不能展示为神经网络的人体置信度。当前球也不画编号文字、运动箭头或速度标签；图中的编号/预测解释只是讲解标注。
