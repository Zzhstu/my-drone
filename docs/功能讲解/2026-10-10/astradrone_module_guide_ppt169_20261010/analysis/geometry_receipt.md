# 关系与几何选择记录

主代理手工撰写22页SVG，没有使用页面生成脚本。文字与图形保持独立可编辑。页面结构先由当前源码关系决定，再选择几何。

| 页 | 页面工作→组合方式→轮廓语言 | 实际关系 |
| --- | --- | --- |
| 01 | 建立主题→文字主场与持续处理区→连续背景场 | 观测、判断、执行及新观测 |
| 02 | 解释包的职责→单块分隔区域→不带方向的文字行 | 各工具箱并列职责，不伪造串行 |
| 03 | 定位校正→双输入汇合→独立处理节点和直线 | 预测与环境约束汇合并更新 |
| 04 | 一次对齐与长期输出→纵向处理后分支→独立节点 | 初始对齐、每帧转换及两个消费者 |
| 05 | 区分候选→条件分支→真实流程判断菱形 | 已有背景与新点两结果 |

轮廓审查：判断、存储、终止和总结方向分别采用原生flowChartDecision、flowChartMagneticDisk、flowChartTerminator、rightArrow。其他真实处理步骤比较过flowChartProcess与圆角独立节点；前者额外强调形式化流程步骤，而本稿不描述可执行流程语言，圆角节点明确表示独立程序阶段，方便较长中文且不会误推条件或存储。职责/显示对应页采用单场文字与分隔线；比较过嵌套卡片和箭头，但它们会暗示不存在的层级或先后关系，故不用。整个页面的矩形背景只表达同一个处理范围，不是数据物体。

本稿没有图像、图表、公式、渐变、阴影或滤镜：当前任务是源码规则关系解释，没有适合新增的实验量化图；平面色和方向线已清晰表达语义，额外质感与装饰效果不增加信息。没有行内强调：强调处独立成标题或提醒，避免中文段落里的不一致字重。上述是用途判断，不是工具能力限制。
