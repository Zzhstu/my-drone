# 可撤销地图维护：图文并茂补充

本合集补充上一版16张讲解图；保留原图，不替换工程代码。不生成PPT。

新增6张3840×2160高清PNG及同名可编辑SVG。第一张采用参考图的“四个上排步骤、三个下排步骤、循环回到下一帧”的排布，每个步骤带较大的点云、无人机、格子、回波或地图插图。后五张用于放大解释，避免把所有规则挤在总图里。

## 图形如何读

- **有颜色的货架点云**：环境结构的示意，不是读入真实PCD得到的实验结果。
- **橙色实体人形**：当前真实行人；即使已经删掉它过去位置的点，现在的人仍是障碍。
- **红色点状人形 / 红色小格**：地图里的历史人体占用，并非本轮运行得到的分割标签。
- **蓝色圆点**：当前激光回波或当前点；回波存在说明这个表面真实被观测到。
- **绿色射线 / 淡绿小格**：真实回波前方的自由观测；并非雷达无回波方向的空间全部为空。
- **空心虚线区域**：过去有占用、现在已撤销的示意位置，不是仍存在的点云。
- **俯视货架外虚线框**：预留安全区域的示意；不是按实际膨胀参数精确绘制的边界。

所有图均为按源码规则绘制的**机制示意**，不是真实仿真截图，不提供新的清理精度、残影数量、路线长度、地图完整率或安全保证。仓库货架和通道借用cangku场景语境，但为简化布局，不是cangku世界几何的精确重建。第03页邻格保护画为投影示意，实际程序检查三维27邻域，不只有图中的二维九格。

## 01 七步图文循环总流程

读图方向：上排左到右（1→4），下排右到左（5→7），箭头回到第2步接收下一帧。

1. 点云图 → 小格记录：第一次合格观测开始形成存储。实际程序先检查观测合格，初始化不是绕过时间检查的独立步骤。
2. 无人机定位与扫描时刻：坐标一致；探索模式时间差不超过0.08秒。没有匹配位姿时等待有界的最新扫描，不借旧位姿制造清空证据。
3. 同格多个蓝点 → 一个代表点：单次回调同格聚合后命中加一次，而不是按点数稳定化。该代码未按唯一采集时间戳去重，不能把这一步讲成严格证明消息相互独立。
4. 射线穿过红色旧格，蓝色回波在更远处：旧占用可能与现在的观测矛盾，但要过保护规则后才能累计。
5. 邻格中的蓝色回波 → 保留：当前结构确实还在，不能因为另一条射线或边界分格而删掉。
6. 计数条：探索模式普通旧格3次、命中至少8次的稳定旧格6次；再次命中清零，过长证据间隔下次重新累计。
7. 三幅小地图：同一个旧格从共享存储删除后，各占用视图在下一次发布都不再输出它。

第一张以**自主探索的证据清理模式**为主，不把普通演示的直接轨迹删除规则混进3/6次保护流程。当前自由观测话题是另一输出，可比持久删除更早影响局部路线，详见06。

## 02 人体离开与地图撤销对比

同一货架通道内依次画出“站着的人 → 已离开的人与旧点 → 射线重新经过旧位置 → 达到条件后的地图”。

想说明的不是“我们已识别所有人体”，而是“允许地图纠正过去的占用判断”。静止人体能入图；未再次观测、遮挡或证据不足处不保证清掉。图里的货架保留仅用于表达保护目的，不代表测得静态保留率100%。

## 03 射线证据与四类误删保护

大图展示一条真正经过旧点的射线，以及四种不授权的情况：

- 前面的货架挡住了回波，后方没有自由证据。
- 同一个格子里，射线没有足够贴近历史代表点（点线容差6厘米）。
- 旧点处于回波终点前0.30米保护段内。
- 当前点落在本格或周围26格，旧格受到邻域保护。

旁边明确时间差0.08秒、命中后至少0.5秒、证据间隔超过1秒重新累计、每个回调每格最多增加一次证据，以及近6米检查范围。这里的稳定门限也不是累计多点的门限，而是该格历史命中回调数至少8次。

## 04 共享存储与多地图视图

左边是格子记录，右边是四种不同用途的输出。

- 持续图：至少2次命中，`/uav1/fastlio/cloud_map`；`/uav1/static_map`是兼容别名。
- 稳定图：至少8次命中，`/uav1/stable_static_map`。
- 局部占用：至少1次、水平半径6米、最近15帧边界内且已空计数为0，`/uav1/local_static_map`。这是发布筛选；局部图看不到某远处点，不代表持续图已删除那个格。
- 当前自由观测：最新射线遍历格，`/uav1/local_free_space`。这个集合比严格的持久删除候选更宽，不能把每个自由格都称为已完成多次确认。

图中的局部半径和货架布置是说明性绘图，不按真实比例；“最近15帧”不等同精确1.5秒的承诺。

## 05 两种清理模式的图解

上半部分是普通演示：确认目标移动后，沿历史经过位置清理圆柱附近旧格，并掩膜拒绝新动点反复入图；历史轨迹保留20秒，掩膜半径0.65米，直接删除半径还加一个0.15米格。普通模式也有射线清理，图只突出区别，没有声称普通模式只有圆柱这一条支路。误确认目标可能伤及邻近货架，不保证稳定旧格免于直接轨迹清理。

下半部分是探索：关闭目标轨迹圆柱直接删除，不根据“目标被认为动态”来擦掉经过空间；当前真实回波参与保护，新点不会被运动目标掩膜拒绝。满足射线、保护和时间规则后才累计3/6次撤销。代价是更依赖再次扫描、位姿和有效时序。

## 06 更新地图如何影响路径

左边画历史点造成的假墙及绕行，右边画旧位置得到修正后可重新考虑的通道。虚线只表达安全预留，没有展示真实测量的净空。

中间特意分成**两条支路**：

1. 当前自由观测修正局部：普通两阶段规划先对匹配的原始三维历史点做剔除，再生成障碍膨胀，最后叠加当前局部占用。不能清空整个膨胀圆盘，也不能用自由线覆盖新的人体占用。
2. 多次确认删除共享记录：持久存储真正更新，持续/稳定/局部视图跟随改变。

局部路线修正可以先于持久删除完成；两者没有完全相同的授权门限。该图是普通两阶段规划的原理示意；仓库黑箱探索由`warehouse_explorer.py`及其探索栅格自行规划，不把A*普通节点说成探索的唯一目标发布器。

## 使用与核验

直接将PNG作为图片插入你后续制作的PPT；SVG可在支持SVG的编辑器中修改。源脚本是`illustrate.py`，重新生成使用系统Python3（PyQt5、Pillow、PyYAML及Noto中文字体），不依赖PPT技能。图片合集ZIP包含所有6张PNG、SVG、预览、说明、生成和核验工具。

```bash
cd /home/a/AstraDroneOpen/docs/功能讲解/2026-10-10/可撤销地图维护_图文并茂补充
python3 illustrate.py
python3 verify.py
```

本轮检查图片渲染、中文文字边界、XML/PNG解码、来源哈希、旧材料未改和压缩包完整性；没有重编译ROS、启动仿真或产生新实验结论。
