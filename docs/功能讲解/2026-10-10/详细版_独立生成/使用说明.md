# 详细版功能讲解：文件与使用方式

这版按用户要求独立制作，没有读取或调用ppt-master技能、模板、生成器、预览器和校验器。使用独立编写的Python脚本生成原生可编辑PPT；旧22页功能讲解、旧42页组会PPT与原网页服务保持不变。

## 可以直接打开的文件

- `无人机功能详解_简图详细版_2026-10-10.pptx`：57页16:9演示文稿。正文、流程方框、箭头可编辑，每页有备注讲稿；不是整页截图。
- 同名PDF：实际打开PPTX后导出的57页静态预览，可以不安装演示软件直接查看。
- `逐页详细讲解与源码位置.md`：逐页正文、补充解释、参数提醒和绝对源码路径。规则例子明确不是新实测。
- `系统总关系图_简洁.svg`、同名PNG：整体关系图的矢量与图片版本；第54页为对应原生可编辑图。
- `简图/`：各正文页面的简单流程图SVG，便于单独引用。
- `验证预览/`：全部57页实际PDF渲染图和10张联系表。

## 相对上一版增加的内容

每个主要模块从“几句话概述”拆成用途、输入输出、具体处理顺序、门限与状态、参数关系、例子、限制和排障。特别展开：

- 定位预测与环境修正、模拟扫描分支、位置和点云一起对齐。
- 前景与运动的区别、聚类配对、多帧速度拟合、地图支持否决与两种平滑。
- 相对运动风险、近场支持点、机体半径与规划膨胀的不同口径、保持和解除规则。
- 一份存储的多地图视图、跨帧命中、普通与探索两种清理模式、射线时间配对、当前回波保护、负证据时效。
- 三维自由证据先撤旧占用再膨胀、当前占用优先、扩域搜索和路线切换滞回。
- 无货架几何先验的探索窗口、未知禁行、前沿增益、慢速原因、受检查短恢复、补扫和结束三个不同指标。
- 启动、真正起飞确认、控制优先级、消息失效、显示对象、地图保存和实际产物目录。
- 行人键盘与无人机键盘的区别，offboard/src全部7个源文件的职责及当前教学代码边界。

页面使用白底、深色文字和少量蓝色标题。正文固定19.5点，主要流程只用3—5个简洁节点；正文细节不挤进图里。总体图用两个分支汇入控制器，并在讲稿说明省略的辅助支线。

## 参数与启动命令提醒

参数以当前配置与launch装配为准。探索最大导航速度当前由launch覆盖为0.30m/s，不能套用旧记录中的0.45/0.55m/s。仓库规划0.80m已含机体0.40m；恢复0.45m只是特殊短恢复下限，不是日常规划距离。融合权重当前静态0.60、动态0.40。

主脚本在项目根目录使用：

```bash
bash scripts/run_sh/dynamic_comparison_demo.sh ours
# 或把上述ours换成badcase
bash scripts/run_sh/warehouse_dynamic_demo.sh
# 上述脚本内部已经固定ours，不要再追加ours
bash scripts/run_sh/warehouse_exploration_demo.sh
```

行人键盘另外打开一个加载同一ROS环境的终端：

```bash
source /opt/ros/noetic/setup.bash
source /home/a/AstraDroneOpen/AstraDrone_ros1_ws/devel/setup.bash
rosrun fastlio_bridge pedestrian_control.py --keyboard
```

等待相应场景移交/准备完成；仓库通常选择0号。W/S是世界+Y/-Y，A/D是世界-X/+X，空格停止，Q退出。这不是控制无人机的offboard键盘程序，不要启动两个飞行设定写者。

## 独立重新生成

内容在`content.py`，排版在`build_deck.py`，验证在`verify_deck.py`。没有依赖PPT技能。

```bash
cd /home/a/AstraDroneOpen/docs/功能讲解/2026-10-10/详细版_独立生成
/home/a/miniforge3/envs/mos-cu128/bin/python3.10 build_deck.py --pdf
/home/a/miniforge3/envs/mos-cu128/bin/python3.10 verify_deck.py
```

依赖当前已有的python-pptx、Pillow、PyMuPDF、Noto Sans CJK SC字体与LibreOffice。修改内容后重新生成会更新本详细版目录中的派生产物，不修改旧PPT、飞行代码或实验文件。文字超限时生成器会报错，要求拆页或修改，而不是自动缩小字号。
