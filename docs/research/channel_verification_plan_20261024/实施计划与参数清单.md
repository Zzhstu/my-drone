# 关键通道主动验证探索：实施计划、参数与验收清单

日期：2026-10-24。状态：设计冻结候选v1，尚未实现或运行新策略。

配套文件：`observed_baseline_parameters.json`为历史航次记录的参数快照；`parameters_draft.yaml`为设计规格，明确禁止直接作为ROS飞行配置加载。本文的参数和目标均不表示已经修改或达到。

## 1. 本轮优化目标与研究边界

在半仓库动态场景及新增机制验证场景中，统一选择前沿观察与地图疑点复查位置；优先处理影响区域连通且可能取得有效证据的疑点，在安全返航预算内获得更多可信地图，并减少无效复查。

首版保持雷达/IMU、固定高度、20cm FAST-LIO前端、15cm维护体素、20cm规划网格、0.60m/s速度上限和安全阈值。地图质量放宽只调整已观测表面的多视角退出目标，不降低占据证据与安全条件。没有新增真实电池模型、全三维飞行或真机节能结论。

最近102949航次仅作为历史参考：解锁至上锁约398s，自由投影599.20㎡，静态参考面直接观测且维护图支持约94.065%，定位RMSE1.186cm；300.07s预算时因1个持久嫌疑进入复查，结果仍报告95个有用前沿，多视角56.05%、质量目标85%、map_quality_accepted=false。性能目标最终应与重新运行的同种子基线比较，不能只挑这一航次。

## 2. 明确验收目标

### 2.1 必须通过的交付与安全检查

| 项目 | 目标 | 判定方式 |
|---|---|---|
| 正常任务预算 | 解锁至上锁≤540s，包含返航、降落；保留60s储备 | 保守解锁时间边界、飞控解锁/空中/上锁证据 |
| 绝对总时限 | ≤600s；启用异常兜底必须标partial/failure，不能冒作正常成功 | 独立监视器及最终审计 |
| 碰撞与错误通道确认 | 测试中0碰撞；0个被判可通行但真值不满足相同机体净空的通道 | 仿真真值只离线评估 |
| 地图交付 | 自动返航、落地上锁、保存PCD及未决清单 | 最终结果及文件一致性审计 |
| 数据完整 | 地图输入无丢失、账本无驱逐/溢出、请求/提交图版本一致、冻结成功 | 沿用现有审计，部分结果明确标注 |
| 定位 | RMSE≤3cm、P95≤5cm、触地前末样本≤4cm | 固定首次对齐、飞行同时间评价，不整轨迹拟合 |
| 静态几何 | 10cm贴合≥99.5%，距离P95≤5cm | 固定真值几何/ROI和容差；这不是鬼影分类准确率 |
| 质量回退保护 | 残影率、静态误删率相对B1各恶化≤0.5个百分点；有安全影响的误删独立判失败 | 先完成标签基线，公开分母/模糊标签 |
| 覆盖回退保护 | 已知自由投影不低于B1的99%；联合静态面覆盖不低于B1减1个百分点 | 同场景分层、配对种子结果；不能要求所有地图都达到599㎡ |
| 实时性 | 探索决策总处理P95≤200ms；新增评价每次预算50ms | 桌面SITL先测，未外推Orin NX；超限用最近可用安全候选 |

以上是待实施后的验收目标，不是已证实的时限/安全保证。若现有监视器只能保证600s而不能保留完整60s，需先完善时间证据和正常返航门控，不把540s写成现有功能已经保证。

### 2.2 预先声明的优化收益目标

- 无效复查执行时间相对B1降低至少25%；B1几乎没有无效复查时，该指标记不适用，不用极小分母制造提升。
- 在预先确定的未饱和场景，同600s总预算下可信静态面覆盖增加至少5个百分点；或达到相同预设覆盖水平的时间降低至少15%。这是研发目标，不承诺实测结果。
- 原半仓库接近覆盖饱和时，优先比较达到同一覆盖水平所需时间和残影/误删，不强行追求599㎡乘以某个比例。
- 同覆盖时间阈值在候选策略运行前冻结：可以取设计基线终点覆盖中位数的95%，且不高于90%；持续至少5s的有效观测才算达到。留出场景的阈值由预定协议给出，不能看候选结果后改。
- 关键通道单独报告正确确认比例、确认时间和未决比例，首轮不编造尚无基线的绝对“成功率”。

性能比较按场景、配对种子统计中位数并报告分布/置信区间。少量试验没有统计显著性时，不能声称可靠提升。安全/质量硬门槛不能用面积改善抵消。

### 5.2 评分与有限展开

| 拟新增参数 | 初值 | 解释 |
|---|---:|---|
| joint_lookahead_depth | 2 | 最多观察两步，不求解全局POMDP |
| joint_lookahead_branching | 6 | 第一阶段筛选后每层最多6个分支 |
| joint_lookahead_discount | 0.70 | 后续收益折扣 |
| joint_weight_area | 0.50 | 新增观测面积收益权重 |
| joint_weight_verify | 0.30 | 有效验证收益权重 |
| joint_weight_connectivity | 0.20 | 验证后潜在可达收益权重 |
| joint_area_scale_m2 | 10.0㎡ | 面积项归一化尺度，裁剪到[0,1] |
| joint_verify_group_scale | 3.0组 | 已按事件优先级与取证质量加权的验证项归一化 |
| joint_connectivity_area_scale_m2 | 20.0㎡ | 预计新增可达的已观测空间归一化；不是已知通道后未知面积 |
| joint_min_evidence_quality | 0.15 | 复查候选质量评分门槛；非15%成功概率 |
| joint_history_review_scale | 0.25 | 仅历史已清除区域复核权重倍率；不把历史事件恢复成当前障碍 |
| joint_score_epsilon_seconds | 2.0s | 防止极近目标时间分母接近0 |

单步原型：`S = (0.50*A + 0.30*V + 0.20*C) / (2 + T_out + T_observe + 0.35*T_home)`。

A/V/C均经上述固定尺度归一化。0.35为旧时间感知评分的返航软代价系数，完整返航代价仍进入硬可行性筛选，不能只预留35%返航时间。有限展开采用边际收益与0.70折扣；同一表面/事件不能跨步骤重复计分，分母按累计动作时间计算。B2只使用面积与简单验证项，连接项为0，其余归一化保持可比较。

首版有效取证质量q使用可解释代理：`q = visible_fraction * range_factor * evidence_factor`。visible_fraction来自当前占据遮挡和实际FOV检查；range_factor在1.2–2.5m取1，2.5–4.5m线性降至0.5；evidence_factor使用`max(0.25, (effective_views+1)/(measured_views+2))`，无记录初值0.5。有效视点必须有实际新扫描并增加自由/正向回波证据，不以到达或重复消息计数。该代理不是独立伯努利概率，也没有校准保证；旧无效证据可降优先级，新视角仍可被评价。视角基线0.70m和端点保护等原门控继续保留。

连接收益只对当前观测支持的区域做临时假设推演，不能将地图未知区用真值填为自由。临时取消嫌疑占据的假设图只用于价值预测，不送入执行器。实际通道确认仍需整段机体净空、当前障碍和观测证据检查。

### 5.3 防止无效复查、目标抖动和算力超限

| 拟新增参数 | 初值 | 解释 |
|---|---:|---|
| joint_target_min_hold_seconds | 3.0s | 安全有效时的最小目标保持；失效立即重规划 |
| joint_switch_improvement_ratio | 0.20 | 普通切换需新目标分数提高20%，减少来回换目标 |
| joint_ghost_action_budget_seconds | 90.0s | 累计复查动作时间，包括旅行与停驻；含复查目标的联合动作也保守全额计入 |
| joint_ghost_cooldown_seconds | 30.0s | 无效观察后同组冷却；新独立证据/显著几何变化可重新评价但不无限重置次数 |
| joint_min_fresh_view_scans | 8帧 | 到位后必须取得独立采集时间戳；不保证8帧即可解决嫌疑 |
| joint_max_view_seconds | 6.0s | 常规仍观察4s；新帧不足时最多6s且先过预算检查，仍不足记未决 |
| joint_low_gain_windows | 2 | 两个45s窗口无有用增益，且无值得执行的候选，才允许低收益退出 |
| joint_extra_compute_budget_ms | 50.0ms | 每次额外评价硬计算预算；留出原路径与控制计算时间 |
| joint_replan_on_safety_invalidation | true | 新障碍、数据过期、坐标/地图版本变化不受3s保持限制 |

一次嫌疑事件原则上最多两个不同视点；冷却结束本身不会恢复无限重试额度。新事件须由实际观测支持，历史清除/保留计数持续保存。预算耗尽后未确认点仍保留为未决或当前占据。RETURNING一旦由硬预算/安全触发，不被收益评分切回探索。

## 6. 对照试验：先排除放宽标准的混杂

| 组 | 调度策略 | 多视角退出目标 | 用途 |
|---|---|---:|---|
| B0 | 原分阶段 | 0.85 | 原demo基线 |
| B1 | 原分阶段 | 0.70 | 单独衡量降低退出要求的影响 |
| B2 | 简单统一探索/复查 | 0.70 | 衡量统一调度本身 |
| B3 | 有效取证＋关键通道价值 | 0.70 | 衡量候选完整策略 |

第一轮三类场景：无动态、通道口行人停留后离开、墙边嫌疑与真实静态障碍对照。每组每场景3个相同行人预设种子，共36次闭环航次作为预实验；根据方差扩展重复、地图和起点。公开空间起点并非给算法真值。

两步分别推进：先在原半仓库做生命周期和质量回退检查；再使用有覆盖余量的更大/遮挡场景检验优化收益。评估通道必须先确认原静态安全配置在对应任务条件下有可行路线，否则不能归因为动态残影阻断。

后续消融包括关闭取证质量、关闭连接收益、关闭历史先验，及保留相同计算预算的短视对照。地面/静态误删与动态残影标签先实现，不以pending=0或10cm贴合率代替。真值只进入离线评价。

## 7. 实施清单与停止条件

- [ ] P0 基线冻结：备份相关源/配置、保存源码和二进制清单、确认旧demo可复现；本轮已完成历史参数提取，但未新运行基线。
- [ ] P1 评价先行：动态观测来源/真值标签、静态误删与未扫描区分、固定ROI、通道净空判定、面积—时间曲线。
- [ ] P2 单纯统一调度：独立策略入口，合并候选，复查后恢复探索；保持原安全、返航和原子地图接线。
- [ ] P3 有效取证预测：基于已有射线/端点/历史诊断计算q并记录预测与实际结果。
- [ ] P4 关键通道价值：有界区域连通组织及两步推演，临时假设不进入安全地图；记录每个评分分项。
- [ ] P5 最小回归：无候选、过期扫描、无法返航、策略切换、地图版本改变、鬼影再次出现、预算将尽、目标抖动、处理超限；仅增加必要行为测试。
