# 有限续航可信主动建图：研究背景、已有工作与论文阅读

整理日期：2026-10-24。适用项目：AstraDroneOpen半仓库探索与动态残影地图维护。

本轮核实范围：原论文摘要、部分相关正文、作者仓库README、出版社页面和出版元数据。不是逐篇全文精读或完整系统综述，未运行作者代码、未复现论文性能。候选贡献尚未经过充分新颖性检索和新实验验证。

## 一、研究背景与问题定位

无人机进入陌生环境后，测量到的空间、能够通行的空间和最终可靠地图之间存在差异。遮挡使某些区域缺乏证据；行人暂时停留后移动，会留下曾经正确、现在失效的占据；传感器与定位误差还可能将静态表面分裂成疑似动态边界。

动态点处理能够改善已取得的观测，却无法凭空获得被遮挡的背景。如果无人机后续不再看到该位置，就可能无法可靠区分真实障碍和旧残影。主动复查需要消耗航程、停驻时间和返航余量，因此必须判断它是否值得执行。

本项目适合研究的问题是：在固定飞行预算内，怎样选择同时有利于新增覆盖和地图疑点验证的观测，让最终可交付的可信静态几何与自由空间尽可能多，并安全返航？

这里的可信是观测证据和离线评价所支持的质量，不是对所有遮挡区域作零鬼影保证。当前首版运动范围仍为固定高度，建图对象是三维点云，不能称已实现完整三维探索或实测能量最优。

## 二、前人已经做过什么

| 技术问题 | 已有代表工作 | 已有方法或认识 | 本项目应如何使用 |
|---|---|---|---|
| 主动选择观察位置 | RH-NBVP | 用有限范围搜索选择信息丰富的观察动作，执行后重规划 | 作为方法基础和短视/滚动规划对照 |
| 减少探索折返 | FUEL、FALCON | 增量维护前沿、全局/局部分层、覆盖路径引导 | 学习访问顺序，采用作者实现时须统一实验条件 |
| 利用历史空闲辨识动态点 | Dynablox、DUFOMap | 维护保守自由空间，利用时空矛盾和射线证据 | 为当前地图维护提供对照；历史和射线本身不作为新颖性证据 |
| 限定预算采集信息 | Popović等的UAV地形IPP | 预算约束下优化信息获取、根据新观测调整计划 | 为时间分配与传感器质量建模提供数学基础 |
| 动态环境主动SLAM | Yang等2026层次NBV | 将动态过滤与视点规划联系起来，考虑可观测性 | 避免笼统宣称首次结合动态处理与主动探索 |
| 地图错误影响探索 | Zhang等2026占据世界模型诊断 | 占据准确度与闭环覆盖效果需分别检验 | 用闭环实验验证地图修正是否真正改善路线 |
| 去动态评价 | DynamicMap Benchmark | 独立评价地图动态点处理并提供多方法比较 | 继承成熟评价思路，再增加主动决策与预算指标 |

以上是基于已查阅材料的主要定位，不表示每篇论文没有覆盖表格以外的内容，也不证明候选方向无人研究。

本项目的FAST-LIO接入、20cm采样配置、15cm维护体素、疑似/清除历史、返航预算和覆盖引导demo属于工程基础。特别是`coverage_path_guidance.py`明确是FALCON-inspired二维引导，不是作者完整FALCON复现，不能把其结果标作原论文方法性能。

## 三、现有项目的研究优势

1. 已有探索—维护地图—主动复查—返航落地—存图链路，可验证决策对实际闭环轨迹的影响。
2. 已有残影历史和真实量测诊断，能研究为什么某次复查没有证据，例如射线未贴近旧点、被静态端点保护或没有足够视角基线。
3. 已有录包、运行参数、源指纹及同输入回放基础，可把地图维护效果和主动规划效果分开。
4. 已有改善后的固定前端基线，后续规划对照可以保持定位、速度、安全参数一致，减少混杂因素。

这些是便于开展研究的条件，不是已经超过论文方法的证据。现有仿真定位收益不能外推真机；鬼影残留真值与静态误删评价仍需补齐。轻量实现和Orin NX部署是工程目标，尚无真机资源测量支持。

## 四、建议聚焦的候选创新

### A. 面向有效取证的残影验证价值预测

问题：进入传感器视野不等于获得能够改变地图判断的证据。

候选方法：结合历史证据、遮挡、射线到旧点的几何关系、视角基线和定位质量，预测某个观察动作能否将嫌疑转为有证据支持的自由、当前占据，或仍未决。验证占据同样可以有价值，不能只奖励删点。

需要证明：在独立场景中，预测分数与实际证据增量有关，能够减少无效复查而不增加静态误删。未经校准的启发式分数不称成功概率。

创新风险：观测质量、信息增益和不确定度规划都有既有研究。候选差异在于旧地图残影事件、真实雷达取证和任务决策价值的具体建模与验证，不能只改名或添加权重。

### B. 考虑验证后可达性的覆盖与复查联合规划

问题：通道入口的一个疑点可能改变后续可达区域，墙边的大量疑点未必有同样价值。

候选方法：统一前沿与复查候选，针对几种可能观测结果做有限展开，估计随后可取得的覆盖收益。预测只用当前观测和地图结构，不能使用仿真真值知道通道后面有多大。

需要证明：在同样预算、地图维护模块和计算预算下，比纯前沿、固定分阶段、简单加权统一调度获得更好的覆盖—残影—误删权衡；分别移除有效性预测和后续价值验证贡献。

创新风险：有限展开、滚动规划和预算优化本身已有工作。贡献必须落在验证结果如何改变后续探索的模型和可复现收益上。临时假设地图不得解除真实飞行的占据约束。

### C. 动态场景下预算受限主动建图的评价方案

候选方法：将同输入地图维护测试与闭环规划测试分开，记录可信静态覆盖、动态残留、静态误删、有效取证率、返航与延迟；覆盖分母和参考ROI预先固定。

需要证明：排除靠少扫、乱删、缩小统计分母获得高分的情况。若进一步公开场景、动态标签和工具，可形成可复用的实验资产。

创新风险：动态点清除已有公开基准，单独增加几项常规指标不自动成为方法贡献。评价更适合作为A/B的证据支撑，是否能独立成为数据集贡献需看规模、标签质量与复用价值。

推荐主线：A+B为候选算法贡献，C提供证据。单目地图复用、全三维飞行、新回环和真实电量模型可以后续扩展，首轮固定这些变量。

## 五、论文阅读清单

### P1：FALCON：覆盖路径引导

- 题名：FALCON: Fast Autonomous Aerial Exploration Using Coverage Path Guidance。
- 作者：Yichen Zhang、Xinyi Chen、Chen Feng、Boyu Zhou、Shaojie Shen。
- 发表：IEEE Transactions on Robotics，卷41，1365–1385，2025刊年；DOI：10.1109/TRO.2024.3522148。
- 年份说明：作者仓库BibTeX和DOI字符串使用2024，本轮Crossref中published-print与issued均为2025；arXiv:2407.00577又于2025-05修订。正式卷年、仓库引用年、预印本修订年应分别说明。
- 已有工作与优势：覆盖路径作为全局引导，配合局部访问顺序和轨迹规划，针对重复访问和折返。
- 精读问题：空间分解/连通图如何更新？全局引导如何约束局部选择？怎样避免每个目标都局部合理而全局低效？
- 与本项目关系：学习区域访问顺序；作者框架是否可以接收我们的验证价值，需要接口和实验核验，不是直接复制体素参数即可。
- [论文](https://arxiv.org/abs/2407.00577)；[DOI](https://doi.org/10.1109/TRO.2024.3522148)；[作者代码](https://github.com/HKUST-Aerial-Robotics/FALCON)。

### P2：DUFOMap：历史自由空间与动态辨识

- 题名：DUFOMap: Efficient Dynamic Awareness Mapping。
- 作者：Daniel Duberg、Qingwen Zhang、MingKai Jia、Patric Jensfelt。
- 发表：IEEE Robotics and Automation Letters，2024；DOI：10.1109/LRA.2024.3387658。
- 已有工作与优势：通过射线确定曾经观测为空的区域，据此辨识动态点，并考虑量测与定位误差。
- 精读问题：什么才算充分观测为空？如何保护薄结构和端点？噪声与定位误差怎样影响自由区域？
- 与本项目关系：直接关联15cm体素和清图证据，适合建立维护模块对照；它不能替代我们主动复查路线的闭环评价。作者仓库展示MID360数据，适配性仍需本地测试。
- [论文](https://arxiv.org/abs/2403.01449)；[作者代码](https://github.com/KTH-RPL/dufomap)。

### P3：Dynablox：保守自由空间和动态检测

- 题名：Dynablox: Real-time Detection of Diverse Dynamic Objects in Complex Environments。
- 作者：Lukas Schmid、Olov Andersson、Aurelio Sulser、Patrick Pfreundschuh、Roland Siegwart。
- 发表：IEEE Robotics and Automation Letters，8(10):6259–6266，2023；DOI：10.1109/LRA.2023.3305239。
- 已有工作与优势：根据在线体积地图估计高置信自由空间，使用时空保守证据辨识动态物体，不依赖固定物体外观类别。
- 精读问题：状态估计与建图限制怎样影响“可信自由”？误检/漏检如何权衡？自由历史如何避免边界错误？
- 与本项目关系：为置信证据和动态检测提供成熟参考。没有证据时保留未决状态，是首版设计应明确支持的结果。
- [论文](https://arxiv.org/abs/2304.10049)；[作者代码](https://github.com/ethz-asl/dynablox)。

### P4：DynamicMap Benchmark：如何证明清得正确

- 题名：A Dynamic Points Removal Benchmark in Point Cloud Maps。
- 作者：Qingwen Zhang、Daniel Duberg、Ruoyu Geng、Mingkai Jia、Lujia Wang、Patric Jensfelt。
- 发表：IEEE ITSC 2023，608–614；DOI：10.1109/ITSC57777.2023.10422094。
- 已有工作与优势：统一地图动态点清除的多方法、多数据比较与评价流程。
- 精读问题：动态点与静态点标签怎样定义？指标怎样平衡去动态与保留静态？位姿误差如何影响比较？
- 与本项目关系：优先解决“正确率到底是多少”的证据缺口。现有基准主要做地图处理比较，我们另需增加闭环覆盖与返航评价。
- [论文](https://arxiv.org/abs/2307.07260)；[作者代码与数据入口](https://github.com/KTH-RPL/DynamicMap_Benchmark)。

### P5：有限预算的信息规划

- 题名：An informative path planning framework for UAV-based terrain monitoring。
- 作者：Marija Popović、Teresa Vidal-Calleja、Gregory Hitz、Jen Jen Chung、Inkyu Sa、Roland Siegwart、Juan Nieto。
- 发表：Autonomous Robots，44:889–911，2020；DOI：10.1007/s10514-020-09903-2。
- 已有工作与优势：用概率地图与传感器模型，在预算约束下在线调整信息采集轨迹，并考虑分辨率与观测范围关系。
- 精读问题：信息价值如何随观测更新？预算怎样进入优化？怎样避免把低质量大范围观察当高质量信息？
- 与本项目关系：适合学习时间/观测质量建模；原任务是地形监测，室内遮挡、障碍通行和动态残影需要重新定义。
- [正式论文](https://link.springer.com/article/10.1007/s10514-020-09903-2)；[开放稿](https://arxiv.org/abs/1809.03870)；[作者代码](https://github.com/ethz-asl/tmplanner)。

### P6：动态环境中的主动语义SLAM

- 题名：Mutual information-based hierarchical NBV decision for active semantic visual SLAM under dynamic environments。
- 作者：Zhenyuan Yang、Ash Wan Yaw Sang、M. A. Viraj J. Muthugala、Mohan Rajesh Elara。
- 发表：Scientific Reports，16:5847，2026-01-20；DOI：10.1038/s41598-026-36259-x。
- 已有工作与优势：结合动态物体处理、全局/局部NBV，以及视觉特征可观测性，研究动态环境中主动定位建图的鲁棒性。
- 精读问题：规划如何应对动态遮挡造成的特征减少？全局信息与局部可观测性如何交互？实验如何评价鲁棒性？
- 与本项目关系：这是需要认真对照的相近方向。我们关注旧LiDAR残影的有效取证及其后续路线价值，不能仅以加入动态过滤作为差异。
- [正式论文](https://www.nature.com/articles/s41598-026-36259-x)。本轮未核实可用作者代码。

### P7：RH-NBVP：滚动视域的基础

- 题名：Receding Horizon "Next-Best-View" Planner for 3D Exploration。
- 作者：Andreas Bircher、Mina Kamel、Kostas Alexis、Helen Oleynikova、Roland Siegwart。
- 发表：IEEE ICRA 2016，1462–1468。
- 已有工作与优势：在线扩展搜索树，以探索收益选择观察动作并滚动重规划。
- 精读问题：分支收益怎样累计？如何避免收益重复？为什么执行一部分后需要重新规划？
- 与本项目关系：说明2–3步前瞻或滚动执行本身属于已有方法；我们需要验证残影观测结果分支的额外作用。
- [作者项目与论文引用](https://github.com/ethz-asl/nbvplanner)。仓库年代较早，代码移植成本需单独评估。

### P8：FUEL：前沿信息结构与分层规划

- 题名：FUEL: Fast UAV Exploration Using Incremental Frontier Structure and Hierarchical Planning。
- 作者：Boyu Zhou、Yichen Zhang、Xinyi Chen、Shaojie Shen。
- 发表：IEEE Robotics and Automation Letters，6(2):779–786，2021；作者注明ICRA 2021 option。
- 已有工作与优势：增量维护前沿信息结构，结合全局路径、局部视点和轨迹规划。
- 精读问题：地图变化影响哪些前沿？可否只重算发生变化的区域？访问顺序如何影响时间？
- 与本项目关系：适合探索调度性能与增量计算的基础阅读；不能把同名“FUEL”误解为论文直接解决电池能量模型。
- [论文](https://arxiv.org/abs/2010.11561)；[作者代码](https://github.com/HKUST-Aerial-Robotics/FUEL)。

### P9：占据错误和闭环探索的关系

- 题名：Diagnosing and Dynamically Filtering Occupancy World Models for Active Mapping。
- 作者：Jiahui Zhang、Gongbo Liang、Yu Zhang。
- 状态：arXiv:2609.06820，2026-09预印本，v2为2026-09-10；本轮未核实正式会议/期刊录用。
- 已有工作与优势：控制规划器、干预占据表示，分析学习式补全错误怎样改变探索，并提出观测驱动过滤。
- 精读问题：为什么占据准确度提高不必然改善终点覆盖？地图错误怎样同时影响收益评分和路径可达性？
- 与本项目关系：支持进行决策层和闭环层评价。论文研究的虚假几何来自学习式补全，我们研究旧动态观测残影，来源不同但机制有关。
- [摘要与版本](https://arxiv.org/abs/2609.06820)；[开放正文](https://arxiv.org/html/2609.06820v2)。本轮未核实可用作者代码。

## 六、建议阅读顺序与每篇产出

第一阶段：P2 DUFOMap → P3 Dynablox → P4评价基准。目标是明确每条清除证据的含义，设计残影和静态保留标签。

第二阶段：P1 FALCON → P5预算IPP → P7 RH-NBVP。目标是画出候选生成、收益计算、预算筛选、执行后更新的数据流。

第三阶段：P6动态NBV → P9占据错误诊断；P8 FUEL用于补充增量前沿与实现效率。目标是形成逐项对照表，明确候选方法的边界与必要消融。

每篇只需先产出一页笔记：任务/传感器、地图状态、候选动作、收益与代价、关键假设、能借鉴的公式或代码、我们的具体差异及验证方法。不要将读过摘要、代码编译成功和完成论文复现混为一谈。

## 七、研究叙述草稿与证据要求

可以使用的研究问题表述：

> 面向有限续航的动态室内无人机建图，研究残影验证的观测有效性及其对后续探索可达性的影响，在保守通行与返航约束下联合安排新区域探索与地图疑点复查。

这段是选题表述，不是已完成的贡献声明。项目优势是已有闭环与证据记录基础，候选优势是更少无效复查和更好的可信覆盖权衡，后者必须用实验支撑。

最小比较采用相同清图模块下的纯前沿、当前分阶段、简单统一调度、候选完整方法，另做预测有效性/历史/后续价值消融。保持前端20cm、维护图15cm、规划20cm、速度和安全、600秒总预算和60秒储备一致。不同闭环轨迹的传感器输入不同，需多场景重复并报告分布；地图维护另用同原始输入对照。

不能直接写成贡献：首次在无人机使用动态清除；首次在体素里保存历史；首次使用有限预算或滚动规划；首次结合动态SLAM与探索；已实现零鬼影；已证明真机节能；受启发demo等于作者完整复现。

配套BibTeX：`active_mapping_reading_20261024.bib`。已有方法设计草稿见同目录`有限续航_可信主动建图_研究方案_20261024.md`。
