# 无行人半仓库：固定相机三高度采集与离线3DGS

用户确认：暂不使用公开数据，原半仓库去掉行人，先采集，再在主机离线训练3DGS。仍是单目RGB＋MID360＋内置IMU，没有深度相机输入。

## 高度问题与本轮方案

原相机为固定安装，无可控俯仰云台。上一轮467航点中428站集中在相对起点1.04m（世界约1.10m），低层只有5站、高层21站；相机光轴基本水平。因此要先增加真实上下层观测，不能靠更长训练恢复被层板遮住且从未观测的真实纹理。

本轮不改相机安装、内参和视场，不让仿真获得实机没有的云台。机体目标世界高度设为：

| 高度 | 主要目的 |
|---|---|
| 0.65m | 下层箱体、低处货架和可见的层板下面 |
| 1.20m | 中层、全局重叠和相邻视点关联 |
| 1.90m | 上层箱体和可见的顶部 |

同一货架两侧各安排不同平移站位，各高度均采集，不仅原地转yaw。原参考mesh/85633固定目标和20cm/双视角40cm基线验收门槛保持；原参考先前排除的不可观测内面不自动宣称已覆盖。

屋顶collision中心Z2.5m、厚0.1m，下表面2.45m。正式1.90m目标到屋顶下表面原点间距为0.55m；这不是旋翼净距或真机安全保证。XY使用连通A*网格，机体原点距二维障碍外形0.80m；新增连续网格边检查（5mm采样余量）和完整压缩线段复查，实际飞行仍由实测点云tube保护。源资产和旧数据/模型不改。

如果实机被严格限制在同一高度，替代办法是带已知角度的相机俯仰机构，或改变固定安装角度分航次采集；每个安装角度需要对应外参，动态俯仰需有每帧关节角。不能只在程序里旋转图片/修改位姿就声称相机拍到了新表面。仅改变俯仰仍可能受层板遮挡，无法保证看见隐藏内面。本轮暂不增加此硬件。
