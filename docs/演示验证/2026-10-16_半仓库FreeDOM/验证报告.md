# 半仓库 FreeDOM 同航次演示验证

运行：`bash scripts/run_sh/half_warehouse_freedom_demo.sh --headless`，输出前缀 `half_warehouse_demo_runs/warehouse_half_20261016_205003`。默认自动行人，无目标数限额、无测试秒数截断。FreeDOM 通过既有 `freedom/astra_mid360_baseline.launch` 旁路读取 FAST-LIO 注册的 body 扫描和位姿 TF，独立构建静态地图；探索器继续使用原维护地图、安全与控制链。场景几何、飞行器、行人、FAST-LIO、传感器、质量验收和运动参数未修改。并行计算使墙钟耗时不能与未运行 FreeDOM 的航次直接作为算法加速比较。

## 核验与边界

新脚本 bash 语法、运行器 Python 语法检查通过。仿真结束两张 PCD 都能重读为有限 XYZ 点，原维护地图 SHA256 与保存元数据相符；FreeDOM PCD 的本次 SHA256 为 `0db3097d50ec787b246e98bd95ef54eb634dd2d9b044b8d2d38eeadb66fcb2bf`。两张 PNG 已目视检查，仓库轮廓和货架排布可辨。ROS/PX4/Gazebo/FreeDOM 本轮进程已退出；FAST-LIO `mat_pre.txt` 已按本轮前 SHA256 `1d2efa2b7dd880a4490d5b5d9fe2a967f32bc5d119c66501de75a4db87840457` 恢复。

FreeDOM 保持此前 MID360 配置，射线增强关闭，不能把这次结果当作论文全配置复现。未进行独立接触真值、动态残影/误删标注、资源 P95、多次重复实验或真实飞行验证。本轮是同一航次下两种独立地图输出的工程演示，未替换机载规划地图。
